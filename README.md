# langium-tools showcases

Working languages that show how to use [langium-tools](https://github.com/borisbrodski/langium-tools) with [Langium](https://langium.org).

Each directory is one showcase. The projects do not share a build. A later showcase is another directory beside the ones already here.

The `statemachine` showcase is the official Langium state-machine example. `upstream` records that example unchanged. `main` extends it.
